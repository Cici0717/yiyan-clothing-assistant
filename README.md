# 衣研｜服饰百科与网购助手

衣研是一款帮助网购用户看懂服装材质与成分标签、比较衣物尺寸，并积累个人穿着体验的轻量工具。项目由静态网页构成，可本地打开，也可以发布为公开网站。

## 页面一览

| 页面 | 主要用途 |
| --- | --- |
| 首页 | 从材质查询、标签解读和尺寸比较等常见任务快速开始。 |
| 材质百科 | 搜索、筛选常见纤维词条，并比较材质特点与适用场景。 |
| 标签解读 | 粘贴商品描述或水洗标文字，整理已知成分比例和待确认信息；不能仅凭文字鉴定实物真假。 |
| 尺寸参谋 | 分上衣、裤装和鞋子，将待购商品数据与穿着效果已知的衣物比较。 |
| 配色与风格 | 根据自选的肤色倾向、穿着场景和风格感受，生成三组配色尝试方向。 |
| 我的衣橱 | 记录材质、尺码、舒适度与穿着体验，支持搜索、筛选及 JSON 备份导入导出。 |
| 个人档案 | 按需保存身体尺寸、穿着偏好和体验敏感项，为后续比较提供个人参照。 |

## 产品需求

完整产品构想、用户问题、功能范围与设计原则见[产品构想与 AI 建站需求](docs/产品构想与AI建站需求.md)。

## 本地运行

可直接打开 `site/index.html`。也可以在 `site` 目录运行静态服务器：

```powershell
cd site
python -m http.server 4317
```

然后访问 `http://127.0.0.1:4317/`。

## 数据与隐私

- 个人档案、衣橱记录、尺寸比较和配色收藏保存在访问者当前浏览器的本地存储中，不会自动上传。
- 本地记录与浏览器及网站地址绑定；清除浏览器数据或更换浏览器后不会自动同步，建议先导出 JSON 备份。
- GitHub Pages 工作流只发布 `site/` 目录；产品需求文档保留在项目仓库中，不包含在网站发布文件里。

## 项目结构

```text
.
├── docs/                 # 产品构想与建站需求
├── site/                 # 可直接部署的静态网站
│   ├── assets/
│   ├── index.html
│   ├── styles.css
│   └── app.js
└── .github/workflows/    # GitHub Pages 自动发布流程
```

项目无需安装前端依赖。材质与规范相关内容在公开发布前应继续补充并核验来源。
